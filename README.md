# Additives

*Supported Versions:*
- BTA! 8.0.1

*Required Dependencies:*
- [Halplibe 6.2.0](https://github.com/Turnip-Labs/bta-halplibe/releases)
- [Babric BTA Instance](https://github.com/Turnip-Labs/bta-fabric-instance-repo/releases)


Mod for BTA! that adds useful additions and fixes to the game.

Everything can be disabled in the config

Current Additions and Fixes:
- Right click harvest, requires hoe. (disable required hoe in config.)
- Fixes mouse cursor displacement bug.
- Disable chat pausing game when open in singleplayer.
- Place ladders on slabs
- Hay beds for sleeping without setting spawnpoint.
